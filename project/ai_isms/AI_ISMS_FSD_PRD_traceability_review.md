# PRD ↔ 기능명세서 추적성 검토 보고서

- 검토일: 2026-06-11
- 대조 문서: `AI_ISMS_PRD_v0.3.md` ↔ `AI_ISMS_FSD_v0.1.md`
- 방법: PRD의 242개 식별 요구사항(FR 217, NFR 25)을 기능명세서 절에 전수 매핑하고, 명세 작성이 불가능하거나 해석이 필요했던 지점을 역추적

## 총평

**커버리지 관점에서는 양호하다.** PRD의 242개 식별자 전체가 FSD에 매핑되었고(누락 0건), MVP 165개 항목은 처리 규칙 수준까지 상세화가 가능했다. 이는 v0.2~v0.3에서 정리한 범위 정합성과 ID 체계가 작동한다는 의미다.

다만 명세 작성 과정에서 **PRD에 정의 자체가 빠진 P0 기능 1건(사용자 관리), MVP 경계가 모순되는 영역 2건(승인, 알림), 산식·규칙 미정의로 FSD가 임의 해석한 항목 9건**이 확인되었다. 임의 해석 항목은 FSD에 `[보완]`으로 표기했으며, 이 해석이 의도와 다르면 PRD가 아니라 구현이 틀어지므로 **v0.4에서 PRD 본문으로 승격해 확정할 것을 권고**한다.

## E. 종합 판정 및 권고

> **반영 완료**: 아래 권고 1~5는 PRD v0.4에 모두 반영되었다(`AI_ISMS_PRD_v0.4.md` 문서 이력 참조). C군 해석도 PRD 본문으로 승격·확정되었다.

**판정: 조건부 적합.** 요구사항의 구조(모듈 분해, ID 체계, MVP 경계, 데이터 모델 연결)는 기능명세서를 만들 수 있는 수준으로 정의되어 있다. 그러나 A-1(사용자 관리 부재)과 B-1(승인 MVP 모순)은 개발 착수 전 반드시 PRD에서 확정해야 하며, C군 9건은 FSD 해석을 검토·승인하는 것으로 갈음할 수 있다.

PRD v0.4 반영 권고 우선순위:

1. **(필수)** 7.21 사용자 관리 절 신설 + FR-USR ID 부여 (A-1)
2. **(필수)** 단일 단계 승인을 MVP 범위로 명시, 17.1/15.1에 조직·범위 관리와 기본 대시보드 추가 (B-1~3)
3. **(필수)** 알림 절 분리 및 FR-NTF ID 부여, MVP 채널 확정 (A-3)
4. (권장) C-1~9의 FSD 해석을 검토 후 PRD 본문으로 승격
5. (권장) FR-CHK-04 용어 수정, 성능 측정 기준 환경 정의 (D-1, D-5)

승인되면 다음 산출물(ERD 초안, API 명세서)은 본 FSD의 FS ID를 기준으로 작성한다.
